# SwiftKanban

A simple Kanban board web app — a mini project built with Vite and vanilla JavaScript.

## Project structure

- `index.html` — main HTML file
- `src/` — source files
  - `main.js` — entry script
  - `style.css` — base styles
  - `assets/` — images and static assets
  - `scripts/` — app scripts (`addTask.js`, `kanban.js`, `toast.js`)
  - `styles/` — component CSS (`kanban.css`, `modal.css`)

## Requirements

- Node.js (16+ recommended)

## Setup

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Notes

- This project uses Vite for development. Edit files under `src/` and the dev server will reload automatically.
- Open the dev server URL (usually http://localhost:5173) to try the app.
